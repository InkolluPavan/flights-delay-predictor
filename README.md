# flights-delay-predictor
✈️ Smart Flight Delay Predictor
A professional, interactive machine learning web application built with Streamlit to forecast flight arrival delays based on historical route data, carriers, seasonal patterns, and departure timing.

🚀 Live Demo
https://flights-delay-predictor-9k4hus3euurmtxvrctjxtd.streamlit.app/

✨ Features
Interactive Route Selection: Choose departure and arrival airports populated dynamically from real airport metadata.

Carrier Filtering: Filter available airlines operating specifically on your chosen route.

Dynamic Schedule Lookup: Select available departure time slots mapped to your chosen route and travel date.

Machine Learning Backend: Employs a robust regression model (Ridge Regression) trained on historical flight performance data.

Custom Dark Theme UI: Styled with a clean, aviation-inspired layout, local background images, and intuitive status banners.
⚠️ Important Limitations & Disclaimer
Historical Data Scope: The underlying machine learning model and schedule lookups were trained and built using historical U.S. domestic flight datasets from 2015 and 2016.

Schedule & Operational Drift: Airline timetables, route availability, airport congestion, and carrier operations change significantly over time. Flight schedules from historical datasets may no longer match modern operational timelines.

Predictive Nature: Predictions generated by this application are statistical estimates based on past patterns. Actual flight conditions are subject to real-time variables such as severe weather, air traffic control initiatives, and unexpected mechanical delays.

Recommendation: This tool is built strictly for educational and portfolio demonstration purposes. Always check directly with your airline or official airport authorities for real-time flight statuses and schedule confirmations.

⚙️ Local Installation & Setup
If you want to run this project locally on your machine, follow these steps:
1. Clone the Repository
git clone https://github.com/InkolluPavan/flights-delay-predictor.git
cd flights-delay-predictor

2. Install Dependencies
Make sure you have Python installed, then run:
pip install -r requirements.txt
3. Run the Streamlit App
streamlit run app.py
📊 Dataset Note
The main training dataset (flights.csv, ~578 MB) is excluded from this repository via .gitignore due to GitHub's file size limits. The pre-trained model artifact (flight_delay_model.pkl) and schedule lookups are already bundled, allowing the web app to run instantly without retraining.
